## Shipped here — local-first news (M18)

`app/news/sections.py` — a pure classifier routing each headline into **Local / City Hall / Opinion / Beyond Havasu** by source + URL path (the clean heuristics the audit found): `lhc_newsflash`→City Hall, `river_scene_news`/`mcso_press`→Local, News-Herald by path (`/opinion/`→Opinion; `/nation`, `/lifestyle/`, `/business/`, `/entertainment/`→Beyond; else Local).

Wired into `app/news/store.py`:
- The **homepage** news module (`ticker_view`) now **drops Beyond Havasu** before the limit, so wire/nation/lifestyle syndication ("Pringles debuts Pop Dog Buns", "California woman killed by Florida alligator") can never run under a Havasu H1 — while it still fills with local headlines.
- Every view item carries `section` + `section_label` so `/news` can tab across the four sections (the tabbed UI is the follow-up).

`tests/test_news_sections_ws13.py` — §8 classifier fixtures + precision + the homepage contract (ticker drops Beyond, `/news` keeps it), 15 cases. Existing `test_news_dedup` stays green.
