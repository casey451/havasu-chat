# WS8 — Mobile & responsive fixes (safe phase)

**Date:** 2026-07-06 · **Branch:** `fix/ws8-mobile-css` (off `main`) · CSS + tests only.

Verified the defects against the current sheet, applied the spec's §8 CSS deltas, and confirmed the fix in the browser preview at **320px and 375px**.

## Confirmed defects (before)

- **M15** — `.gseg{display:inline-flex}` had **no `flex-wrap`** and **no `@media`** touched it (the narrowest breakpoint was 430px), so the 4-grade selector overflowed and clipped **"Diesel"** at 375px (standard iPhone). Buttons were ~31px tall (< 44px).
- **M16** — `.counts{display:flex}` with `white-space:nowrap` pills, **no wrap, no scroll** → the pill row (still rendered on `/events-ui`) clipped on a phone.
- **M17** — `.tpill` (movie/showtime pills) were ~20px tall — below the 44px minimum tap target.

## Fixes (`app/static/styles/lake_redesign.css`)

- **M15:** `.gseg{flex-wrap:wrap}`; `.gseg.lg button{min-height:44px}`; `@media(max-width:430px){ .gseg.lg{display:flex;width:100%} .gseg.lg button{flex:1 1 45%} }` — a 2×2 grid that always shows Diesel. **[Render §1]**
- **M16:** `.counts{flex-wrap:nowrap;overflow-x:auto;scroll-snap-type:x proximity;scrollbar-width:none}` + hidden webkit scrollbar; `.cpill{scroll-snap-align:start;min-height:44px}`.
- **M17:** `.tpill{min-height:44px;display:inline-flex;align-items:center;padding:8px 12px}` (kept `text-decoration:none` so the movies parity test holds).
