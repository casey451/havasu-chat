## The gap (proven by fixture probe)

Probing the current engine against all 18 §14.1 pairs (keeper with place_id/reviews + a review-less
GLH twin at the same address, no phone): **0 of 18 cluster.** Reasons:
- the name+address signal needs the name key **equal**, but the twin's name differs
  (`denny-s-restaurant` ≠ `denny-s`);
- the slug-family token-subset signal requires a **matching phone** (a precision guard against
  merging a brokerage with its named agent — `test_token_subset_with_different_phones_does_not_cluster`).

## Change in this PR (high-precision, zero existing-test regression)

**New engine signal — generic-subset (`app/dedupe/cluster.py`):** at the **same address**, union two
rows with **no phone** when one name (after dropping articles/`and`/possessive-`s`) is a subset of the
other **and every extra token is a generic cuisine/venue descriptor** (`restaurant`, `mexican`,
`pizza`, `pasta`, `steak`, `house`, `kitchen`, `cocktails`, …). This set is deliberately **disjoint
from the parent/child hint set** — words that double as department markers (`cafe`, `bar`, `grill`,
`taproom`, `deli`) are excluded, so "Safeway"/"Safeway Deli" stays parent/child and a
brokerage-plus-named-agent never merges. `test_generic_subset_does_not_merge_a_person_extra` pins that.

**§14.1 fixtures as tests (`tests/test_dedupe_ws4_fixtures.py`), two tiers:**
- **9 auto-merge** (twin adds only generic descriptors) — now cluster as `duplicate`: Denny's, Niko's
  (`&`↔`and`), Rosati's, Filiberto's, Montana's, Rusty's, Bad Miguel's, Sloane's, The Spot.
- **8 review-tier** (xfail, documented target) — need trigram/fuzzy or de-conflicting a venue word
  that doubles as a department hint: Shugrue's, Hangar 24, Kokomo (symmetric-diff); Lin's/Lina (typo),
  Dos Amigos (plural typo); The Office, McKee's (`grill`), Broken Yolk (`cafe`). Per the spec these are
  the ".70–.85 borderline → human review queue" cases; the xfail flips to pass when that tier lands.

All existing `test_dedupe_cluster.py` precision guards stay green (71 passed, 8 xfailed).
