## The one real fix — Website on unclaimed listings

The Website button **and** the "Visit website" link were both gated behind `not vm.show_claim_cta` (`show_claim_cta = tier_is_free and not verified`), so an **unclaimed, free-tier** provider — most of them — showed **no website** even when the URL was known (it was still embedded in the page's own "Suggest an edit" link). The audit found exactly this on Siddhartha's Garden / In-N-Out / Altitude.

**Casey's call (2026-07-06): always show the website.** Removed `and not vm.show_claim_cta` from both surfaces, so any provider with a stored URL shows the Website button + link, claimed or not. The claim CTA still renders alongside it.

- `tests/test_provider_action_row_website.py` — updated the docstring + added `test_website_button_shows_on_unclaimed_listing` (unverified + website → button shows); the existing claimed-case and no-website tests stay green.
