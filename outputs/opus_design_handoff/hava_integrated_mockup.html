The integration in one diagram

One card grammar everywhere. A class card, a gym card, a restaurant card, a kids-event card, and a chat result card all share the same shell. The status line carries the content type:
Green status = place ("Open until 9pm") Lake status = event ("Tonight at 6:00pm")
Three front doors, one stream. Browse (category tiles → category landing), Search, and Ask Hava all return mixed streams of place + event cards in the same component. There is no separate "events finder" — events live wherever the user is browsing, searching, or asking.
Time-windowed discovery is built into the chip system, not bolted on. The time chips ("Now / Tonight / Weekend") sit in the locked Row 3 alongside operational chips. When active, the stream weights time-proximity for both place hours and event start times.
The profile gains one new region. "What's on at [venue]" conditionally inserts between service details and hours+location for any venue with linked events. Carries its own freshness indicator distinct from the venue's verification band.
