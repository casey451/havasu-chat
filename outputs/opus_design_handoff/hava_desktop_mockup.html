Mudshark Brewery

Brewery & American · McCulloch district · 1.2 mi from English Village
● Open until 10pm · happy hour 4–6pm
Last verified 4 months ago — hours and menu may have changed. Call ahead to confirm.

About

Local brewery and full kitchen since 1997. Wide patio with outdoor seating, dog-friendly outside, full bar with their own taps and a rotating guest list. Their IPA and wood-fired pizzas are the regulars' picks. Live music on Friday and Saturday nights.

McCulloch district

The main strip running south from the bridge — busy after work and on weekends. Parking is easier than English Village. Heavy snowbird crowd Nov–March; tourist crowd thins after spring break.

How mobile and desktop relate

Same templates, responsive breakpoints. Server-rendered Jinja with CSS media queries handles both. The components don't fork — the Hava card, freshness band, chip system, district context, photo gallery, and "What's on" region all use the same partials and the same CSS classes.

Single-column mobile → 2/3/4-column desktop happens entirely in the grid container. The card itself doesn't know whether it's in a 1-col or 4-col grid.

Mobile bottom-sheet map (A7) → desktop persistent map column. Same Leaflet instance, different positioning. On mobile it's a slide-up sheet; on desktop it's a sticky right rail.

Mobile sticky status bar (A9) → desktop sticky action sidebar. Same goal (keep actions visible during long scroll), different implementation: mobile gets a slim top bar, desktop gets a full action card.

Mobile app-head → desktop top nav. The mobile version compresses to logo + boat toggle; the desktop expands to the full nav with search, browse, and Ask Hava CTA. Both are the same template with conditional rendering on viewport width.
