How this slots into the locked design

The chip-row pattern, freshness band, Hava card grammar, and district context all reuse the existing components — events get the same visual language as places. The new pieces are a third entity type (Event), a chronological time-axis view, and a Schedule region that inserts into the 11-region profile for class-driven venues. The chat surface gains the highest leverage from this content type because "yoga tonight" is exactly the kind of grounded, time-aware, hyperlocal query that generic search and a generic LLM both fail.
